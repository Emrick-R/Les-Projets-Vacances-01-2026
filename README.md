# Les-Projets-Vacances-01-2026

Ce répertoire contient les projets pour les vacances d'hiver 2025-2026.

## Structure du Répertoire

- `calculatrice/` : Projet de création d'une calculatrice simple en Golang avec interface web.
- `convertisseur-Unités/` : Projet de développement d'un convertisseur d'unités en Golang avec interface web.
- `quizz/` : Projet de création d'un quiz interactif en Golang avec interface web.
- `jeu-nombre-mystere/` : Projet de développement d'un jeu du nombre mystère en Golang avec interface web.

## Instructions
Chaque projet est autonome et contient son propre code source, fichiers de configuration et documentation. Pour chaque projet, lancer dans le terminal la commande ci dessous pour démarrer l'application web correspondante.

```bash
go run main.go
```
Ensuite, ouvrez votre navigateur web et accédez à l'URL suivante pour interagir avec l'application :

```http://localhost:8080
```
